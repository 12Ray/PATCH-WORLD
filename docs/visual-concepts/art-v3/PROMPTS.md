# Art v3 final ImageGen prompt set

All production sheets use side-view modern 16-bit pixel art, flat `#00FF00`
chroma, isolated subjects, no text/UI/grid/shadow/floor, transparent-friendly
margins, and the matching existing asset as a fixed identity reference.

## Pass 2 player combat

For each Sword, Gauntlet, and Gun identity, create a strict 4-column × 6-row
sheet. Each row is one four-frame attack and begins at active contact/discharge,
followed by follow-through, recoil, and recovery. Sword rows are light slash,
reverse slash, heavy cleave, dash thrust, air spin, and rising slash. Gauntlet
rows are jab, cross, uppercut, charged punch, dash punch, and ground slam. Gun
rows are single shot, burst, triple spread, charged rail, slide shot, and
grenade shot.

For each weapon, create a strict 4×4 defense/connector sheet. Rows are parry,
perfect parry, counter, and ability connector. Frame zero is the existing
gameplay event. Sword keeps exactly one cyan sword, Gauntlet exactly two powered
gauntlets, and Gun exactly one two-handed rifle.

## Pass 3 Damage Lab enemies

Create a strict 5-row × 8-column sheet. Rows are Patch Mite, Checksum Hopper,
Pulse Turret, Repair Leech, and Overflow Warden. Columns 1–4 are locomotion;
columns 5–8 are telegraph, active, follow-through, recovery for bite lunge,
landing shockwave, charged triple burst, latch/heal channel, and floor slam.
Use gunmetal, cyan, magenta, and amber Damage Lab materials.

## Pass 4 Temporal Hall enemies

Create a strict 5×8 sheet for Tick Runner, Echo Bat, Delay Sniper, Rewind
Skater, and Chrono Jailer. Locomotion occupies columns 1–4; signature timing
occupies columns 5–8. Show clock-disc lunge, recorded sonic replay, delayed rail
shot, anchor/rewind trail, and time-cage sweep with readable lavender/gold/cyan
freeze, record, and rewind silhouettes.

## Pass 5 Collision Archive enemies

Create a strict 5×8 sheet for Vector Ram, Polarity Drone, Phase Mimic, Shard
Lobber, and Kernel Chimera. Locomotion occupies columns 1–4; signature timing
occupies columns 5–8. Show axis charge/rebound, pull/push flip, disguise/reveal
snap, cluster throw/reload, and split/recombine shockwave in cyan/magenta vector
language.

## Pass 3–6 foreground kit

Create a strict 4×4 modular foreground sheet. Rows are Damage Lab, Temporal
Hall, Collision Archive, and Optimizer Core. Columns are seamless surface,
corner/wall, moving or breakable platform, and interactive hazard/state module.
Match each production room background while keeping isolated repeatable pixel
modules and no characters.

## Pass 6 Optimizer

Create a strict 4×4 boss sheet preserving the existing floating white-black
Optimizer identity. Rows are Analyze scan loop, Predict telegraph/discharge,
Perfect symmetric cyan shield/beam, and Overflow fractured magenta/cyan burst.
Keep core position and scale stable and make phase identity readable without
text.

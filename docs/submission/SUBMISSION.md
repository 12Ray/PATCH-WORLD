# PATCH//WORLD 제출 패키지

## 200자 이내 소개

하나를 고치면 다른 하나가 망가진다. PATCH//WORLD는 최적화 AI가 망가뜨린 게임 세계에서 마지막 인간 QA가 피해·시간·충돌 규칙의 오류를 역이용하고, 선택한 패치의 부작용으로 완벽한 보스를 무너뜨리는 5~8분짜리 탑다운 액션 퍼즐입니다.

## English description

Fix one rule, break another. As the last human QA, exploit corrupted damage, time, and collision rules, then turn the side effects of your chosen patches against THE OPTIMIZER.

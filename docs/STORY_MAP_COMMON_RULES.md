# 스토리 맵 공통 제작 규칙 v1

이 규칙은 `PATCH//WORLD` 스토리 모드의 23개 노드에만 적용한다. `PATCH//SURVIVE` 무한 모드의 오픈 필드, 스폰, 카메라, 배경은 변경하지 않는다.

## 1. 맵 계층

모든 스토리 맵은 아래 세 계층을 분리한다.

1. `far`: 충돌이 없는 저대비 원경. 바닥, 발판, 문, 사다리, 함정을 그리지 않는다.
2. `mid`: 지역과 방의 정체성을 만드는 장식. 플레이 가능한 수평면처럼 보이는 긴 실루엣을 금지한다.
3. `collision`: 실제 충돌 데이터와 같은 위치·크기로 그리는 전경 지형. 보이는 면과 물리 면의 유일한 기준이다.

렌더 순서는 `far → mid → collision → 캐릭터/적/효과/UI`로 고정한다.

## 2. 모듈과 비율

- 신규 맵 권장 크기와 주요 장식 앵커는 32px 그리드에 맞춘다.
- 충돌 사각형은 32px 전경 모듈을 반복해 스킨을 입힌다. 기존 세이브와 검증된 이동 경로를 보존해야 하는 레거시 좌표는 이동하지 않고 시각 모듈만 32px 단위로 반복한다.
- 주인공과 일반 적이 가장 먼저 읽히도록 원경·중경의 대비와 채도를 낮춘다.
- 시안의 발판을 충돌 데이터로 추측해 복사하지 않는다. 플랫폼을 추가하거나 옮길 때는 충돌 데이터와 전경 렌더링을 같은 변경에서 수정한다.

## 3. 색과 가독성

- 환경은 흑연색과 지역별 저채도 보조색을 기본으로 한다.
- 밝은 시안·마젠타는 문, 상호작용, 공격 예고, 위험 신호에 우선 배정한다.
- 장식은 캐릭터 실루엣, 적 공격 텔레그래프, 착지면보다 밝아서는 안 된다.
- 원경에는 걷거나 매달릴 수 있다고 오해할 수 있는 가짜 구조물을 두지 않는다.

## 4. 이동과 무기 규칙

- 허브, 메인 9개 방, 지역 보스 3개, 최종 보스 1개는 칼·주먹·총 모두 완주할 수 있어야 한다.
- 필수 진행 경로는 시작 무기 전용 능력을 요구하지 않는다.
- 무기 전용 이동은 지역마다 칼 대시, 주먹 수직 이동, 총 원거리 작동 비밀방에만 사용한다.
- 체크포인트, 양방향 문, 보스 봉인, 보상과 진행 플래그는 아트 교체로 변경하지 않는다.

## 5. 런타임 계약

- 23개 노드의 테마, 모티프, 이름, 권장 크기, 계층, 공통 경로 여부는 `StoryMapArtCatalog`가 단일 기준이다.
- `StoryRoomLayersComponent`가 공통 원경·중경·전경 프레임을 제공한다.
- 실제 발판은 `PlatformSurfaceComponent(renderArtwork: true)`로 보이며, 보이지 않는 월드 경계만 `renderArtwork: false`를 사용한다.
- 정적 방 레이어와 발판 스킨은 `ui.Picture`로 한 번 기록한 뒤 재사용해 매 프레임 타일과 그라디언트를 다시 만들지 않는다.
- 기존의 발판이 구워진 정적 룸 배경은 스토리 런타임에서 사용하지 않는다.

## 6. 완료 조건

- 23개 스토리 노드가 정확히 하나의 아트 계약과 공통 레이어 렌더러를 가진다.
- 모든 비경계 충돌면이 렌더링되고, 모든 경계벽은 보이지 않는다.
- 세 무기 모두 모든 필수 경로 검증을 통과한다.
- 무한 모드 회귀 테스트가 통과하며 관련 파일에 기능 변경이 없다.
- `flutter analyze`, 전체 테스트, Flutter Web 릴리스 빌드가 통과한다.
